# Определение ориентации текста каскадным способом

Решение предсказывает вероятность того, что текстовый кроп повёрнут на 180.
Итоговый файл submission.csv с колонками image_id, p_180.

## Подход

1. Две компактные модели ориентации обрабатывают исходное изображение и его
   копию, повёрнутую на 180.
2. Три OCR модели сравнивают уверенность чтения в обеих ориентациях.
3. Эти сигналы объединяются в базовый прогноз.
4. Если уверенность не ниже 0.85, прогноз сохраняется без изменений.
5. Для остальных сложных изображений подключаются английский OCR, латинский OCR и доп.
   PP-OCRv6-small. Их сигналы уточняют только этот небольшой хвост

Поворот меняет классы местами, поэтому прогнозы исходника и R180 объединяются
в пространстве логитов

Результаты на закрытом тесте Avito:

 E2: 0.98662396
 E5 cascade: 0.98809675
 уменьшение Brier ошибки: около 11%

## Файлы

solution.ipynb — краткое описание и удобный запуск по ячейкам;
 run.py — весь inference в одном читаемом Python-файле;
 config.json — зафиксированные веса, масштабы и порог `0.85`;
 e1_model/ — веса дообученной модели ориентации;
 submission.csv — отправленный результат;
 requirements.txt — версии библиотек.

## Запуск

Проверено на Python 3.12, Windows и NVIDIA GPU.

Установка зависимостей:

```powershell
python -m pip install paddlepaddle-gpu==3.3.1 -i https://www.paddlepaddle.org.cn/packages/stable/cu129/
python -m pip install -r requirements.txt
```

Запуск:
python run.py `
  --images ..\images `
  --sample ..\sample_submission.csv `
  --output reproduced_submission.csv

Быстрый запуск:
python run.py `
  --images ..\images `
  --sample ..\sample_submission.csv `
  --output sparse_submission.csv `
  --mode sparse

Пути `..\images` и `..\sample_submission.csv` предполагают, что папка с изображениями и `sample_submission.csv` лежат рядом с папкой репозитория.

Официальные OCR-модели Paddle скачиваются автоматически при первом запуске
Можно также открыть solution.ipynb
Режим exact используется по умолчанию и воспроизводит отправленный CSV.
Он сохраняет исходный размер batch для дополнительных OCR, поскольку
предобработка PaddleOCR немного зависит от состава batch. Режим sparse
быстрее и действительно отправляет в дополнительные OCR только сложные кропы,
но может дать небольшие численные отличия.

На RTX 5070 exact-воспроизведение занимает примерно 37 минут. Sparse-режим —
около 12–13 минут.
